# Made by Zimbos — coming soon

A responsive static landing page for GitHub Pages. It uses plain HTML and CSS; there is no build step or server-side code.

## Files

- `index.html` — page text, image descriptions, and scrolling preview cards
- `styles.css` — design, responsive layout, and scrolling animation
- `images/` — optimized copies of the supplied photos and flyers

## Preview locally

Extract this folder, then open `index.html` in a browser. Keep `styles.css` and the `images` folder beside it.

## Publish with GitHub Pages

1. Create a separate public repository for this site. Keep app and API source code in their own repositories.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages** and choose the `main` branch and `/ (root)` as the publishing source.
4. Add `madebyzimbos.com` as the custom domain in the Pages settings and follow GitHub's DNS instructions.
5. In Squarespace DNS, add only the website records GitHub provides. Leave the Google Workspace mail records intact.
6. When the DNS check passes, enable **Enforce HTTPS** in the Pages settings.
